比肩主页的分页背景方案

主页用了 WebGL 流体模拟才达到那个效果——分页要追平，答案也是 WebGL Shader

现状

主页：WebGL 流体模拟（~995行），有鼠标交互、Bloom 后处理

分页：纯 CSS 渐变脉冲（~20行/主题），肉眼几乎看不出区别

落差巨大 — 进分页像从影院走进了走廊

方案

每个分页用 WebGL Fragment Shader 做独立的全屏视觉效果

每个 Shader 约 150-300 行 GLSL，风格完全不同

和主页同级别的视觉冲击力，但每个页面有自己的"性格"

6 个 Shader 概念

浏览器里看效果 — 每个都是 CSS 模拟，实际实现用 GLSL 会更细腻

Flow Field 流场

粒子沿着噪声场流动，像风吹麦浪

Aurora 极光

多色光带在星空下流动，北欧夜空

色彩旋涡缓慢旋转，能量场感

Geometric Pulse 几何脉冲

同心环交错旋转+星点闪烁，精密感

技术实现思路

主页的 FluidBackground.tsx 已经用了 WebGL — 新增的 Shader 可以复用它的 GL 上下文管理、resize 处理等基础设施。

每个分页的 Shader 是一个独立的 .tsx 组件，通过 client:visible 懒加载，只在滚动到视口时才初始化 WebGL。

Shader 之间共享一套 uniform（时间、分辨率、鼠标位置），但各自的 fragment shader 完全不同。
